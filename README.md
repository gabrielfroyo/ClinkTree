# ClinkTree
A BallTree constructed using Clink

This project was an experiment in using complete-linkage clustering to form a binary tree. The result was a ball tree with a bottom-up construction time complexity of O(n^2).

An algorithm most similar to this is the Q algorithm found in “Optimized 2D Ball Trees”. The major difference is that the Q algorithm is dynamically programmed.

This project also has a github-pages associated with it, which is an interactive web page that helps visualize the ClinkTree.
